# Поиск инсайтов и точек роста

Сервис доставки еды «Всё.из.кафе»: как повысить удержание пользователей и улучшить работу с ресторанами-партнёрами.

## Задачи
- Анализ воронки и пользовательского пути
- RFM-сегментация пользователей
- Кластеризация ресторанов (K-means)

## Стек
Python, pandas, NumPy, matplotlib, seaborn, SciPy, scikit-learn

## Результаты
- Главная точка потерь — шаг `confirm_phone`, особенно на mobile
- Самый массовый RFM-сегмент — «средний класс» с редкими заказами и невысоким чеком; отдельно выделены «киты» с высоким вкладом в выручку
- Рестораны разделены на 4 кластера с разными стратегиями работы
