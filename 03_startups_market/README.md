# Исследование рынка стартапов

Анализ финансирования 54 294 компаний за 2000–2014 годы для фонда, который хочет покупать и перепродавать стартапы.

## Задачи
- Предобработка: типы, дубликаты, пропуски, восстановление дат финансирования
- Сравнение типов финансирования по объёму, распространённости и возвратам
- Поиск растущих рыночных сегментов и расчёт нормированной доли возвратов

## Стек
Python, pandas, NumPy, matplotlib, seaborn

## Результаты
- 59% компаний получили один раунд, но 61,9% всех денег привлекли компании, которые финансировались дольше года
- `Venture` доминирует по объёму и возвратам; у `private_equity` самый устойчивый рост доли возвратов
- Самый быстрорастущий массовый сегмент — `Medical`: +172% финансирования в 2014 году
- Рекомендация: сегмент `Medical` с `private_equity` как основным типом финансирования
