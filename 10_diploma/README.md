# Дипломный проект: анализ маркетплейса и A/B-тест

Итоговый кейс курса: обзор метрик маркетплейса, юнит-экономика, поиск точек роста и анализ эксперимента с бонусом на первую покупку.

## Задачи
- Обзор ключевых метрик и метрик монетизации (AOV, ARPU, ARPPU)
- Поиск инсайтов и сегментация по воронке
- Подведение итогов A/B-теста

## Стек
Python, pandas, NumPy, matplotlib, seaborn, SciPy, statsmodels

## Результаты
- Конверсия выросла с 1,06% до 7,51%, ARPU с 9,87 до 68,14 (оба изменения значимы)
- ARPPU и средний чек значимо не изменились
- Итог: бонус на первую покупку увеличил конверсию и выручку, не ухудшив поведение платящих пользователей
