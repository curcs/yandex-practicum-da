# Исследование рынка общепита Москвы

Исследовательский анализ 8 406 заведений Москвы по данным Яндекс Карт и Яндекс Бизнеса для инвесторов, которые выбирают формат нового заведения.

## Задачи
- Объединить и очистить данные о заведениях и ценах
- Изучить категории, округа, сетевой статус, вместимость, рейтинги и средний чек
- Оценить связи рейтинга с признаками через Phi-k

## Стек
Python, pandas, matplotlib, seaborn, phik

## Результаты
- Рынок держится на кафе, ресторанах и кофейнях; в ЦАО 2 242 заведения, около четверти выборки
- Более половины булочных, пиццерий и кофеен сетевые, то есть эти форматы хорошо масштабируются
- Медианный чек в ЦАО 1 000 ₽ против 600 ₽ в остальных округах
- Связь рейтинга со структурными признаками слабая (максимум Phi-k ≈ 0,22 у ценовой категории)
