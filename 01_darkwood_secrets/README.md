# Секреты Тёмнолесья

Исследование поведения игроков в фэнтези-игре на основе данных о покупках 
и активности персонажей.

## Задачи
- Доля платящих игроков и структура покупок
- Статистика трат: средний чек, медиана, аномалии
- Сравнение активности по расам персонажей

## Стек
PostgreSQL

## Данные
Схема `fantasy`: таблицы пользователей, событий, предметов и рас персонажей
