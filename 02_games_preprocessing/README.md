# Предобработка данных о продажах компьютерных игр

Подготовка датасета о продажах игр (16 956 строк) к анализу.

## Задачи
- Привести названия столбцов и типы данных к корректному виду
- Разобрать служебные значения `unknown` и `tbd`, обработать пропуски
- Найти и удалить неявные дубликаты
- Собрать срез за 2000–2013 годы и категоризировать оценки критиков и пользователей

## Стек
Python, pandas

## Результаты
- Удалено 512 строк (≈3% данных), из них 235 полных дубликатов после нормализации текста
- Пропуски региональных продаж заполнены средним по платформе и году выпуска, пропуски оценок оставлены как `NaN`
- Срез `df_actual`: 12 781 игра; топ-7 платформ: PS2, DS, Wii, PSP, X360, PS3, GBA
